# Hyprland Cheat Sheet

Essential shortcuts for navigating and managing the environment in Hyprland.
The **Super** key (`mainMod`) corresponds to the Windows/Cmd key on your keyboard.

## 🚀 Launch & System

| Action | Shortcut | 
| ----- | ----- | 
| **Open App Launcher (Rofi)** | `Super + Space` | 
| **Open Terminal (Kitty)** | `Super + Q` | 
| **Open File Manager (Yazi)** | `Super + E` | 
| **Close active window** | `Super + C` | 
| **Exit Hyprland (Logout)** | `Super + M` | 

## 🎯 Navigation, Focus & Layout

| Action | Shortcut | 
| ----- | ----- | 
| **Change window focus** | `Super + Arrow keys` | 
| **Toggle Fullscreen** | `Super + F` | 
| **Toggle Floating mode** | `Super + V` | 
| **Toggle Pseudo-tiling** | `Super + P` | 
| **Toggle Split direction** | `Super + J` | 

## 🪟 Window Manipulation

| Action | Keyboard / Mouse Shortcut | 
| ----- | ----- | 
| **Move window (Keyboard)** | `Super + Shift + Arrow keys` | 
| **Move any window (Mouse)** | Hold `Super` + **Left Click** & drag | 
| **Resize window (Mouse)** | Hold `Super` + **Right Click** & drag | 

## 🖥️ Workspaces

| Action | Shortcut | 
| ----- | ----- | 
| **Go to workspace 1 to 9** | `Super + 1` to `9` | 
| **Scroll through workspaces** | `Super + Mouse wheel` | 
| **Move active window to workspace X** | `Super + Shift + 1` to `9` |
